# Implementation phases

## Phase 1 — Foundation
Monorepo, navigation, design system, sample data, API health and tests.

## Phase 2 — Intake and processing
Unit submissions, document upload, parsing status, chunk review and metadata enrichment.

## Phase 3 — Intelligence
Multi-label heading affinity, evidence pools, deduplication and conflict resolution.

## Phase 4 — Synthesis
Section planning, AI-assisted drafting, source grounding and recursive parent synthesis.

## Phase 5 — Governance and publication
Review workflows, versioning, final report preview, export controls and analytics.

## Production hardening backlog
PostgreSQL/pgvector, SSO/RBAC, malware scanning, OCR workers, DOCX/PDF generation, object storage, queues, audit immutability, model observability and deployment pipelines.
