Current cycle

Convert the v7 tree module from a development-grade persistent implementation into a concurrent, permission-secured, fully tested module.
  • Verify clean Node/React build.
  • Replace structure JSON repository with database tables and migrations.
  • Add authenticated project membership and backend authorization.
  • Add optimistic locking for concurrent editing.
  • Add Playwright tests for create, move, import, restore and reload.

Critical risks

Build not independently verifiedNode dependency installation timed out in the build environment.
JSON persistenceAtomic writes reduce corruption but do not support safe concurrent users.
Authentication and RBACCurrent development identity is not a production security boundary.
Import fidelityComplex layouts, floating text boxes, embedded images and merged tables need representative corpus testing.

Definition of done

  • User action works in the interface.
  • API validates and performs the operation.
  • Database persists it after restart.
  • Permissions are enforced server-side.
  • Errors are actionable and recoverable.
  • Audit event is recorded.
  • Automated tests cover success and failure.
  • No mock, fake progress or placeholder behavior.

Update protocol

Every development response that changes the application must also update this file's:

  • revision number and date;
  • feature status and progress;
  • release-history entry;
  • current cycle and next action;
  • risks and test evidence.
